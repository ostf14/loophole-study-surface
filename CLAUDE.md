# Loophole Online — Study Surface

Тестовое задание: один экран платформы подготовки к LSAT — plan header и day
timeline view из PRD «Study Surface». Рабочий экран в браузере, не статичный
макет: код должен уходить их инженерам (Fullstack House, TypeScript/React)
без переписывания.

## Дизайн-система

Токен-слой целиком в `app/globals.css`, снят с продакшн-сборки
`new.theloophole.com` и из файла Figma `LO Design System (FSH Update)`.

Правила, без которых экран выглядит чужим:

- Только семантические токены. `text-caption-medium`, никогда `text-xs`.
  `text-pewter-hc`, никогда `text-gray-500`.
- Отрицательный трекинг есть у каждого текстового токена, дефолтные классы
  Tailwind его не дают.
- Веса 400 в системе нет: body 500, caption 600, title 700, display 800–900.
- Необрутализм: рамки 2–3px soft-black, жёсткие тени без размытия, сдвиг
  вверх-влево на ховере через `lh-card-hover-*` у карточек и арбитрарный
  сдвиг с тенью у кнопок.
- Наклон как мотив: чекбокс поворачивается на 8° при отметке и наведении,
  галочка внутри `PositionIcon` зафиксирована под 9.72°. Воспроизводить
  везде, где есть отметка о выполнении.
- Иконки только из `lucide-react`.
- Интерлиньяж брать из CSS, а не из Figma — там расхождение, прод важнее.
- Данные в интерфейсе доменные и настоящие, не заглушки.
